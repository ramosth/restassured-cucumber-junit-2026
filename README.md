# RestAssured + Cucumber + JUnit 5 (ServeRest)

> 🚧 Projeto em construção.

Automação de testes de **API REST** com **Java 17, RestAssured, Cucumber (BDD, Gherkin em português) e JUnit 5**, usando a API de estudos [ServeRest](https://serverest.dev) (login com token, usuários, produtos e carrinhos).

Faz parte do meu portfólio de automação, depois dos projetos de UI com Selenium:

|---|---|

| [selenium-cucumber-testng-2026](https://github.com/ramosth/selenium-cucumber-testng-2026) | Selenium + Cucumber + TestNG (UI) |
| [selenium-cucumber-junit-2026](https://github.com/ramosth/selenium-cucumber-junit-2026) | Selenium + Cucumber + JUnit 5 (UI) |
| **restassured-cucumber-junit-2026** | **RestAssured + Cucumber + JUnit 5 (API)** |
